# КРУГ

Адаптивный одностраничный сайт современной кофейни. Интерфейс на русском языке, фотографии созданы специально для проекта.

## Запуск

```bash
npm start
```

Откройте `http://127.0.0.1:4173`.

## Проверка

```bash
npm run check
```

Сайт не требует сборки и внешних зависимостей: готовая версия находится в `dist/`.
